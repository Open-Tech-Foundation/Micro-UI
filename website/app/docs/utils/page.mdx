# Micro-UI Utils

Micro-UI Utils is a small, semantic, framework-free CSS utility and component layer for Micro-UI apps. It has no Tailwind or Bootstrap dependency and requires no build step.

```js
import "@opentf/micro-ui/styles.css";
```

## Split imports

Pay only for the layers you use:

```js
import "@opentf/micro-ui/styles/tokens.css";
import "@opentf/micro-ui/styles/base.css";
import "@opentf/micro-ui/styles/components.css";
```

Or load the full bundle from a CDN:

```html
<link rel="stylesheet" href="https://unpkg.com/@opentf/micro-ui/dist/styles.min.css">
```

## Theming

Override CSS custom properties in your app:

```css
:root {
  --ui-primary: #2563eb;
  --ui-primary-hover: #1d4ed8;
}
```

Dark mode is automatic through `prefers-color-scheme: dark`. An explicit `data-theme="dark"` or `data-theme="light"` wins over the system preference, and themes can be applied to individual containers.
